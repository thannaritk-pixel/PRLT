PRLT Fractal
PRLT

Probabilistic Reversal Learning Task

ฉบับ fractal ของเว็บแอป PRLT: 160 trials, reward 80/20, fixed reversals หลัง trial 55, 70, 90, 105, 125 (Waltmann et al., 2022) พร้อม counterbalance 2 versions สำหรับ test-retest

Counterbalance: ครึ่งหนึ่งของผู้เข้าร่วมเริ่ม S1 ด้วย V1 อีกครึ่งเริ่มด้วย V2 และ S2 ใช้ version ตรงข้ามกับ S1 เสมอ ใช้ coded ID เท่านั้น ห้ามกรอกชื่อหรือ HN

นิยาม behavioral columns

stay = เลือก stimulus เดียวกับ trial ก่อนหน้าที่ตอบ · win_stay/lose_stay = stay แยกตามผลของ trial ก่อน · consec_loss = จำนวน loss ติดกันจนถึง trial ก่อน · persev_opportunity = 2 trial ที่ตอบล่าสุดไม่ได้แต้มทั้งคู่จากรูปเดียวกัน และรูปนั้นเป็นรูปที่ผิดใน trial ปัจจุบัน · perseverate = เลือกรูปนั้นซ้ำ (Waltmann et al., 2022) · คอลัมน์ choice_num, outcome, missed, rt (วินาที), reversal_this_trial เข้ากันได้กับไฟล์ PsychoPy v8.1 · post_reversal_5 = 5 trials แรกหลัง reversal · reversal_triggered = 1 ที่ trial สุดท้ายก่อน contingency เปลี่ยน · trial ที่ไม่ตอบ (miss) ไม่ได้แต้มและนับเป็น trial ตามตาราง
